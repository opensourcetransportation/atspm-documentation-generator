## Generated configuration and log reference

The generated documentation is stored in
[`docs/autogenerated`](docs/autogenerated/index.md). It has separate pages for
[Speed Emitter](docs/autogenerated/speed-emitter.md) and the
[declared Event Listener configuration](docs/autogenerated/event-listener.md), plus
[structured log events](docs/autogenerated/log-messages.md) and a
[configuration change report](docs/autogenerated/configuration-changes.md).

`GenerateDocuments/documentation.json` maps the two annotated C# sections to
their correct pages. New properties appear automatically. A newly annotated
section needs an explicit page assignment, because the generator cannot know
whether it belongs to the emitter or listener. Source XML comments supply
descriptions. Keep the generated snapshot and hidden ownership manifest in Git.

**Runtime status:** `SpeedEmitterConfiguration` is bound by `HostBootstrapper` and
can be overridden by the emitter command, environment or appsettings. The
`EventListenerConfiguration` class is declared under that exact section name,
despite its file being called `SpeedListenerConfiguration.cs`. The listener
command currently has no handler, the listener background service throws
`NotImplementedException`, and this repository has no local registration/binding
for `EventListenerConfiguration`. Its generated page describes source defaults
and intended settings, not a working listener deployment.

The reference preserves source defaults: emitter host `127.0.0.1`, port `1088`,
protocol `Udp`, interval `100` milliseconds; listener batch size `50_000`, UDP
port `10088`, and lowercase `threads` value `50`. The numbers in the **Default**
column are C# source expressions, not a measurement of deployed values.
`HostBootstrapper` separately validates a nonblank emitter host, port from 1 to
65535, and positive interval. The **Required** column only reflects property
annotations. The CLI labels protocol choices as UDP/TCP, while its option type is
the wider .NET `ProtocolType` enum; review runtime protocol behavior before using
other values.

The emitter calls `AddAtspmDbContext` and `AddAtspmEFConfigRepositories` from
`Utah.Udot.Atspm.Infrastructure` version `5.3.1`. Configuration types supplied
only by that package are outside this repository's source scan. See
[`docs/dependency-configuration.md`](docs/dependency-configuration.md) for source
provenance and the coverage limit. The generator does not assert that those
external settings are absent from a deployment.

The **Update generated documentation** workflow scans source, checks section
coverage and structured log IDs, validates the site, and proposes a draft PR to
`documentation-integration`. It does not run the application. Replace both
`REPLACE_WITH_COMMIT_SHA` values with the same reviewed generator commit before
the workflow can run. Inspect an artifact-only preview with `create-pr: false`,
then set it to `true` to enable draft PRs. Actions settings must permit PR
creation. Nothing merges or publishes documentation automatically.

The first snapshot establishes a baseline; later reports compare the documented
source contract. Examples contain placeholders and are not deployment settings.
